Persistence note

Accounts are saved in SQLite, so a registered user can log in directly next time on the same deployment. On Render's free tier, the local SQLite file resets when the service is redeployed or restarted with a fresh filesystem — that is a Render free-tier limit, not an admin-panel bug. For permanent accounts across redeploys, move the database to Postgres or add a paid Render Disk later.
